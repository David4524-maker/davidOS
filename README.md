### Requisitos minimos:

Navegador web: Google Chrome, Mozilla Firefox, Microsoft Edge o Safari con soporte actualizado para HTML5 y JavaScript (ES6+).

Procesador (CPU): 1.0 GHz o superior (Cualquier procesador multinúcleo moderno).

Memoria RAM: 512 MB de RAM disponibles para la pestaña del navegador.

Almacenamiento: Menos de 5 MB en disco para guardar configuraciones locales (localStorage).
